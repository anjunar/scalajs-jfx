Runtime
Property
A Property<T> holds a value; text() renders it, and derived state re-renders when its source does.
Derived state
map() derives a Property from another; observe()/observeWithoutInitial() run a side effect; disposeWith() ties it to the page.
when and forEach
when() mounts a body while a condition holds; forEach() reconciles a body per list item; classIf() toggles one class reactively.
fetchInto
Renders asynchronously loaded data in place; SSR waits, hydration tolerates it still loading.
Lifetime and hydration
isBrowser()/isHydrating()/hasScope() report the environment; capture() lets composition resume later; mount() renders fresh into an unclaimed element.

One runtime. Two APIs.

Build with TypeScript. Run on JFX.

The TypeScript API is a language-level entrance to the same reactive, SSR-capable runtime as the Scala.js DSL.
