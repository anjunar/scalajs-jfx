Suche

Finde jedes Beispiel über Titel, Zusammenfassung oder Stichwort.

  • Carousel
    Eine wiederholende Diashow über einer ListProperty.
  • ComboBox
    Eine durchsuchbare Einfachauswahl, an ein Formularfeld gebunden.
  • Formulare komponieren
    subForm() und arrayForm(): ein verschachteltes Modell und ein wiederholendes Feld.
  • Kontext und Nebenläufigkeit
    Ein asynchroner RouteLoad, RouteContext.params/queryParams/failure und eine Ziffern-Bedingung mit Fallback über onFailure.
  • DataGrid
    Zellen fester Größe in einer responsiven Spaltenzahl, virtualisiert über eine lokale Quelle.
  • Abgeleiteter Zustand
    map() leitet eine Property ab; observe() und observeWithoutInitial() führen Seiteneffekte aus; disposeWith() bindet sie an die Seite.
  • Editor
    Ein Lexical-basiertes Rich-Text-Feld, wie input per Namen gebunden.
  • Alles zusammen
    property, listProperty, forEach, when und classIf in einer kleinen Anwendung.
  • DSL erweitern
    element() baut einen Tag-Wrapper in einer Zeile; attr, style, domProperty, on, onDoubleClick, addClass und self bilden jeden Wrapper.
  • fetchInto
    Rendert asynchron geladene Daten an Ort und Stelle; SSR wartet, Hydration toleriert den Ladevorgang.
  • Formular und Modell
    Ein dekoriertes FormModel aus Property-Feldern, per Namen an Controls gebunden.
  • ImageCropper
    Schneidet ein hochgeladenes Bild auf ein festes Seitenverhältnis zu, bevor es das Modell erreicht.
  • Lebensdauer und Hydration
    isBrowser(), isHydrating() und hasScope() melden die Umgebung; capture() setzt Komposition später fort; mount() rendert frisch in ein nicht beanspruchtes Element.
  • Verschachtelte Route
    routerOutlet() und eine Kindroute – eine Verschachtelungsebene.
  • Nicht gefunden
    Eine unbekannte Route mit ihrem eigenen HTTP-Status.
  • Benachrichtigung
    Ein Toast im gemeinsamen Viewport-Layer.
  • Overlay
    Eine positionierte schwebende Ebene – das Grundelement für das ComboBox-Dropdown.
  • Übersicht
    Was @anjunar/jfx-* ist und wo du startest.
  • Property
    Eine Property<T> hält einen Wert; text() rendert ihn und abgeleiteter Zustand rendert bei Änderungen neu.
  • RemoteSource
    Eine sparsam geladene Datenquelle für dasselbe tableView(), das auch eine lokale ListProperty verwendet.
  • routerLink
    Ein navigierender Anchor mit activeClass – ein echtes <a href>, daher funktioniert Navigation ohne JavaScript.
  • Schema-basiertes JSON-Mapping
    Decoratoren und JsonMapper bilden eine TypeScript-Klasse mit umbenannten Feldern, IDs und ListProperty-Werten ab.

    Finde jedes Beispiel über Titel, Zusammenfassung oder Stichwort.
  • TableView
    Eine virtualisierte Tabelle mit sortierbarer Spalte und crawlbarem SSR-Pager.
  • Tabs
    Eine Reihe von Panels, jeweils eines gemountet.
  • Validatoren
    Alle 22 eingebauten Validatoren, je einer pro Feld – TypeScript-Decoratoren werden zu Annotationen für die unveränderte Scala-Validierung.
  • VirtualListView
    Gemessene Zeilenhöhen, eine Spalte, virtualisiert über eine lokale Quelle.
  • when und forEach
    when() mountet einen Body solange eine Bedingung gilt; forEach() gleicht einen Body pro Listenelement ab; classIf() schaltet eine Klasse reaktiv.
  • Fenster
    Ein verschiebbares schwebendes Panel über der gerouteten Seite.
