routerLink

Ein navigierender Anchor mit activeClass – ein echtes <a href>, daher funktioniert Navigation ohne JavaScript.

ÜbersichtDiese SeiteEin defekter Link (funktioniert auch ohne JS)
import { classes, div } from "@anjunar/jfx-core";
import { routerLink } from "@anjunar/jfx-router";
import { translated } from "../../app/i18n.js";

export function routerLinksPage(): void {
  div(() => {
    classes("flex", "gap-3");
    routerLink("/", translated("Overview"), { activeClass: "text-accent" });
    routerLink("/router/links", translated("This page"), { activeClass: "text-accent" });
    routerLink("/no-such-route", translated("A broken link (still works without JS)"));
  });
}
Hinweis

RouterConfig akzeptiert auch ein basePath – jede Route und jeder routerLink wird darunter aufgelöst, um die gesamte Anwendung unter einem URL-Präfix (etwa einem Reverse-Proxy-Pfad) zu mounten. Hier wird das nicht live verwendet: Die Routen, Navigationslinks und der Suchindex dieser Demo gehen von keinem Präfix aus. Ein Präfix würde das Umschreiben aller hartcodierten Pfade erfordern, nur um die Option zu demonstrieren. Die Option ist seit CLAUDE_REVIEW_3.md unverändert – siehe RouterConfig in router.ts von @anjunar/jfx-router.
