Welcome to JFX 3

Reactive Scala.js interfaces with SSR and hydration built into the same component model.
Start with working code
A Property drives the text, and the event updates that same state after hydration.
scala
import jfx.core.dsl.EventDsl.onClick import jfx.core.layout.Button.button import jfx.core.layout.TextComponent.text import jfx.core.layout.VBox.vbox import jfx.core.state.Property val count = Property(0) vbox { text(count.map(n => s"Count: $n")) {} button("Increment") { onClick(_ => count.set(count.get + 1)) } }
