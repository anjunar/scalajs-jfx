In-memory RemoteListProperty
The loader slices and sorts one generated Vector.
scala
val books = RemoteListProperty[Book, BookQuery]( loader = RemoteLoader { query => val sorted = sortBooks(generatedBooks, query.sorting) val page = sorted.slice(query.offset, query.offset + query.limit) Future.successful( RemotePage( items = page, offset = Some(query.offset), totalCount = Some(sorted.length) ) ) }, initialQuery = BookQuery(offset = 0, limit = 50), rangeQueryUpdater = Some((query, offset, limit) => query.copy(offset = offset, limit = limit) ) )
